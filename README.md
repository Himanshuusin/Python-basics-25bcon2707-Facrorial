Factorial Program in Python

About

This project contains a beginner-level Python program to calculate the factorial of a non-negative integer.

How to Run

1. Make sure Python is installed on your computer.
2. Open a terminal in the folder containing factorial.py.
3. Run the command:

python factorial.py

4. Enter a non-negative integer when prompted.

Learning Objective

* Understand Python variables.
* Learn how to take user input.
* Practise loops and multiplication.
* Display output using the print() function.
